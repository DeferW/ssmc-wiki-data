# SSMC Wiki

SSMC Wiki — неофициальная модульная база данных и набор веб-инструментов для
**Space Stories Marine Corps**. Проект разделён на два репозитория:
[`ssmc-wiki-data`](https://github.com/DeferW/ssmc-wiki-data) собирает данные из
исходников игры, а [`ssmc-wiki-app`](https://github.com/DeferW/ssmc-wiki-app)
показывает их пользователю.

- [Планы и TODO](https://github.com/DeferW/ssmc-wiki-app/blob/main/docs/ROADMAP.md)
- [Руководство контрибьютора](https://github.com/DeferW/ssmc-wiki-app/blob/main/docs/CONTRIBUTOR_GUIDE.md)

## Этот репозиторий

`ssmc-wiki-data` преобразует прототипы, локализацию и ресурсы игры в стабильные
JSON-контракты и готовые ассеты для сайта. Сгенерированные файлы находятся в
`data/` и не редактируются вручную.

## Архитектура

```text
исходники игры + config/
          ↓
scripts/<module>/
read → resolve → normalize → validate
          ↓
data/<module>/
JSON-контракт + ассеты
          ↓
ssmc-wiki-app
```

```text
config/              редактируемая конфигурация сборщиков
scripts/common/      общая инфраструктура чтения данных игры
scripts/<module>/    изолированный сборщик предметной области
data/<module>/       опубликованный результат этого сборщика
.github/workflows/   проверки и воспроизводимая публикация
```

Каждый модуль владеет своим входным преобразованием, публичной схемой,
валидатором, тестами и выходной папкой. Общий код выносится в `scripts/common/`
только при наличии нескольких реальных потребителей.

Публичным интерфейсом для приложения является документ модуля в
`data/<module>/`, обычно `catalog.json`. Диагностические индексы и промежуточные
файлы контрактом сайта не являются и могут меняться без обратной совместимости.

Изменение публичной схемы сначала реализуется и публикуется здесь, после чего
поддержка новой версии добавляется в `ssmc-wiki-app`.
