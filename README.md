# Данные химического каталога SSMC Wiki

Репозиторий собирает данные о химии из `MetalSage/space-stories-cm14` и подготавливает их для страницы `MC:Химия`.

Это не копия игрового репозитория. Скрипты объединяют разрозненные YAML, русскую локализацию и разделы игровых руководств в один готовый JSON, который может прочитать браузер.

## Зачем нужен отдельный репозиторий

MediaWiki не может получить содержимое папки GitHub одним запросом, разобрать игровые YAML-теги, восстановить наследование реагентов и связать рецепты с локализацией.

Этот репозиторий выполняет подготовку заранее:

1. Загружает нужную часть актуальной ветки `master` игры.
2. Находит реагенты, реакции и их зависимости.
3. Разрешает наследование свойств реагентов.
4. Подставляет русские названия и описания.
5. Распределяет вещества по разделам игровых руководств.
6. Проверяет ссылки, происхождение данных и итоговые счётчики.
7. Публикует готовый `data/chemistry-catalog.json`.

## Как это связано с вики

На странице `MC:Химия` находится контейнер:

```html
<div id="scmc-chemistry-app">Загрузка химического каталога…</div>
```

`MediaWiki:Common.js` подключает `MediaWiki:ScmcChemistry.js` и CSS только на этой странице. Скрипт запрашивает:

```text
https://raw.githubusercontent.com/DeferW/ssmc-wiki-data/main/data/chemistry-catalog.json
```

После загрузки JSON интерфейс строится прямо в браузере. Репозиторий должен оставаться публичным, иначе вики не сможет получить файл без авторизации.

## Какие данные используются

Workflow загружает из `MetalSage/space-stories-cm14` только эти пути:

```text
Resources/ServerInfo/Guidebook/_RMC14/Chemicals/OT.xml
Resources/ServerInfo/Guidebook/_RMC14/Chemicals/Medicine.xml
Resources/ServerInfo/Guidebook/_RMC14/Guides/RMCGuideDrinks.xml

Resources/Prototypes/_RMC14/Reagents
Resources/Prototypes/_Stories/Reagents
Resources/Prototypes/_RMC14/Recipes/Reactions
Resources/Prototypes/_Stories/Recipes/Reactions

Resources/Prototypes/Reagents
Resources/Locale/ru-RU
```

Папки `_RMC14` и `_Stories` дают содержимое самого каталога. Базовые `Prototypes/Reagents` используются для родителей и ингредиентов, на которые ссылаются пользовательские рецепты. XML-руководства определяют разделы каталога, а `ru-RU` — названия и описания.

## Структура репозитория

```text
.github/workflows/build-chemistry-catalog.yml  # запуск сборки

scripts/extract_guide_sections.py              # читает разделы руководств
scripts/index_chemistry.py                     # индексирует YAML-прототипы
scripts/build_chemistry_catalog.py             # собирает итоговый каталог

data/chemistry-guides.json                     # промежуточные данные руководств
data/chemistry-index.json                      # промежуточный индекс YAML
data/chemistry-catalog.json                    # файл, который читает вики
```

Файлы в `data` создаются автоматически. Править их вручную не нужно.

## Как обновить каталог

1. Открыть вкладку **Actions**.
2. Выбрать **Build chemistry catalog**.
3. Нажать **Run workflow** и подтвердить запуск для ветки `main`.
4. Дождаться зелёной отметки.
5. Обновить `MC:Химия`; при необходимости использовать `Ctrl + F5`.

Обычно сборка и появление нового файла занимают несколько минут. Если исходные данные не изменились, workflow завершится без нового коммита.

Для ручного запуска нужны права **Write**. В личном репозитории они выдаются через `Settings → Collaborators → Add people`.

## Что делает workflow

```text
master игры
    ↓
chemistry-guides.json + chemistry-index.json
    ↓
chemistry-catalog.json
    ↓
проверка
    ↓
автоматический коммит от github-actions[bot]
    ↓
MC:Химия
```

В итоговом JSON сохраняются хеш коммита игры и время сборки. Публикация отменяется, если каталог пуст, найдены неизвестные ссылки, перепутано происхождение прототипов или не совпадают контрольные значения.

## Ограничения

- Обновление запускается вручную и берёт только ветку `master`.
- Новые файлы учитываются только внутри перечисленных выше путей.
- Реакции из других папок автоматически в каталог не попадут.
- Каталог рассчитан на русскую локализацию `ru-RU`.
- Изменение структуры YAML, XML, наследования или типов эффектов может потребовать правки Python-сборщика или JS на вики.
- Вики читает только `chemistry-catalog.json`; удаление этого файла приведёт к ошибке загрузки каталога.
- Если удалить всю папку `data`, следующий успешный запуск Action создаст её заново. До этого `MC:Химия` работать не будет.
- Если Action завершился с ошибкой, старый успешно собранный каталог остаётся доступным и не заменяется сломанным результатом.

## Если обновление не появилось

1. Проверить, что Action завершился зелёной отметкой.
2. Открыть последний коммит и убедиться, что `data/chemistry-catalog.json` изменился.
3. Проверить, что изменения игры уже находятся в `master` и лежат в отслеживаемых путях.
4. Обновить страницу без кеша через `Ctrl + F5`.
